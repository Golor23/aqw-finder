ABOUT THE PROJECT

Made for category-first discovery.

AQW Item Finder searches every item’s structured metadata. A search for face mask prioritizes an item’s type, category, and tags before checking its description or name.

Using your own data

The included data/items.json is a small development sample, intentionally separate from the app. Replace it with a valid JSON array using the same fields. The browser loads it dynamically, so the interface does not need to change as your collection grows.

This independent fan-made tool is not affiliated with or endorsed by Artix Entertainment.
